# CS 350 – Emerging Systems Architectures and Technologies

## Project Reflection

**Summarize the project and what problem it was solving.**

For this course, I worked on several projects using a Raspberry Pi and Python to control different hardware components. Two projects I chose for my portfolio were the thermostat and Morse code projects. The thermostat used a temperature sensor, buttons, LEDs, and an LCD display to monitor temperature and respond to user inputs. The Morse code project used LEDs and buttons to send messages while displaying the system's status on the LCD. Both projects helped me understand how software and hardware work together.

**What did you do particularly well?**

I think I did a good job troubleshooting problems and getting everything working correctly. There were several times when the code or hardware didn't work as expected, but I was able to work through the issues and figure out what needed to change. I also became more comfortable working with the Raspberry Pi and connecting different components.

**Where could you improve?**

One area I could improve is writing cleaner code from the beginning instead of making changes as I go. I would also like to get better at troubleshooting hardware issues without having to spend as much time figuring out where the problem is.

**What tools and/or resources are you adding to your support network?**

This course gave me more experience with Raspberry Pi, Python, GPIO, I2C, and working with hardware components. I also became more familiar with using documentation, troubleshooting resources, and GitHub to organize and share my projects.

**What skills from this project will be particularly transferable to other projects and/or course work?**

The biggest skills I gained were troubleshooting, Python programming, and understanding how software communicates with hardware. I also learned more about state machines and how they can be used to manage different system behaviors. These are skills I can apply to future programming projects and other courses.

**How did you make this project maintainable, readable, and adaptable?**

I worked on keeping my code organized and using comments to explain what different sections were doing. Breaking the functionality into separate sections also made it easier to troubleshoot and make changes without affecting the entire program. This should make the projects easier to update or expand in the future.
